# افسانه‌ی ناتمام — The Unfinished Legend

بازی پلتفرمر پیکسل‌آرت برای اندروید ⚔️🧟

یک بازی کامل با ۳ مرحله، مبارزه با شمشیر، زامبی‌ها، سکه، جعبه‌های گنج، تله‌ها و پلتفرم‌های متحرک — با رابط کاربری فارسی و کنترل‌های لمسی.

---

## 📱 دانلود و نصب بازی

۱. فایل **`AfsaneNaTamam.apk`** را از بخش [Releases](../../releases) دانلود کنید

۲. فایل را به گوشی منتقل کنید و روی آن بزنید

۳. اگر گوشی پیام «نصب برنامه‌های ناشناس / Unknown sources» داد، اجازه‌ی نصب را بدهید

۴. بازی را اجرا کنید! 🎮

> نیازمندی: اندروید ۵ به بالا (API 21+) — بدون نیاز به اینترنت — اجرای افقی

## 🎯 هدف بازی

با شمشیر با زامبی‌ها بجنگید، سکه‌ها را جمع کنید، از تله‌ها و پرتگاه‌ها رد شوید و در هر مرحله به پرچم برسید. **۳ مرحله** دارید و **۵ قلب**. جعبه‌ها را باز کنید تا سکه و قلب بگیرید!

## 🛠 باز کردن پروژه در GameMaker

فایل ZIP را Extract کنید و در GameMaker Studio 2 از منوی **Open > Open Project** فایل `AfsaneNaTamam.yyp` را باز کنید.

پروژه شامل ۲۵ اسپرایت، ۱۸ آبجکت با کد GML کامل، و ۴ اتاق (منو + ۳ مرحله) است. برای خروجی اندروید از منوی **Create Executable > Android** استفاده کنید.
